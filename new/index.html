Phase 01 · Code Generation

C Source → Three-Address Code

Three-Address Code (TAC) is an intermediate representation where each instruction has at most one operator and three operands. It's the bridge between high-level source code and machine-level operations.

The compiler parses your C input, resolves expressions, and emits sequential TAC instructions — breaking complex expressions into atomic steps, assigning temporaries, and linearising control flow (loops, conditionals).

Phase 02 · Tree Construction

TAC → AST & Parse Tree

The Abstract Syntax Tree (AST) captures the hierarchical semantic structure of your program — stripping away syntactic noise like parentheses and punctuation, retaining only what matters for code generation and analysis.

The Parse Tree (Concrete Syntax Tree) is the full structural record of every grammar rule applied during parsing. Together, they give you a complete picture of how the compiler understood your code.
